PropertyNest — Real Estate Listing Platform

PropertyNest is a responsive real-estate listing platform that allows users to browse, search, filter and sort property listings, view detailed property information and submit buyer enquiries. Sellers and agents can also publish new property listings. The project includes a Node.js JSON API, SQLite database storage, server-side validation and automated API testing.
